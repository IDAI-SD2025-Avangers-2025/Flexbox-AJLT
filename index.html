Ejemplos sobre los diferentes tipos de Flexbox



¿Qué hace cada propiedad?

El Flexbox de Ejes/Direcciones modifica el diseño de los datos posicionandolos en diferentes lugares dentro de la pagina web.


El Flexbox Alineación de Elementos modifica el diseño de los datos posicionandolos en diferentes lugares dentro de la pagina web y altera el tamaño de cada elemento.


El Flexbox Alineación de elementos multilínea modifica el diseño de los datos posicionandolos en diferentes lugares dentro de la pagina web y altera el tamaño de los elementos por igual.


El Flexbox Alineación individual modifica el diseño de los datos posicionandolos en diferentes lugares dentro de la pagina web y altera el tamaño de un elemento individualmente.


El Flexbox Propiedades elementos hijos modifica el diseño de los datos posicionandolos en diferentes lugares dentro de la pagina web todos los datos que esten dentro de la div de un hijo.


Conclusión

La función del Flexbox consiste en cambiar el orden de posición de cada elemento Flex para adaptarse a cualquier dispositivo sin que afecten al codigo principal.
